# טיוטות משפטיות לפיילוט

הקבצים בתיקייה הזו הם טיוטה פנימית. הם לא מדיניות מאושרת.

הטקסט זהה לעמודים תחת `/legal`, חוץ מקובץ זה. העמודים וההודעות בטפסי האורח והמארח כבויים עד שמפעילים את הדגל.

## איך מפעילים אחרי אישור

1. ממלאים כל `[להשלמה: …]` ומסירים או מעדכנים כל שורה שמתחילה ב־`⚠️`.
2. מגדירים בשרת `LEGAL_DRAFTS_ENABLED=1` (גם `true`, `yes`, או `on`). כל ערך אחר, כולל חוסר משתנה, משאיר את הטיוטות חבויות. זה נכון גם ב־Production.
3. פורסים מחדש. עמוד אורח סטטי נאפה עם ערך הדגל של אותה פריסה.
4. לא מוסיפים את `/legal` לתפריט הציבורי לפני האישור.

העמודים מסומנים `noindex`. שער הבטא הקיים עדיין חל על `/legal`, כי החבילה הזו לא משנה את השער. אורח שנכנס מקישור אירוע בלי עוגיית בטא וילחץ על מדיניות הפרטיות יועבר למסך הבטא.

## מה כלול

- `privacy.md` — מדיניות פרטיות
- `terms.md` — תנאי שימוש
- `pilot.md` — תנאי השתתפות בפיילוט, הדגמה בלבד
- `retention.md` — שמירה ומחיקה
- `rights.md` — פנייה וזכויות, בלי כתובת דוא״ל
- `notices.md` — ההודעה לאורח וההודעה למארח
